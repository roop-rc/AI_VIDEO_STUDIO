# 1. Master Visual Direction

The film uses a **stylised cinematic 3D storybook aesthetic**.

> A warm, handcrafted cinematic animated storybook brought into
> dimensional 3D, with appealing stylised characters, tactile materials,
> soft atmospheric lighting, expressive cinematography and restrained
> magical realism.

## Core Style Vocabulary

``` text
stylised cinematic 3D animation
storybook-inspired
handcrafted
tactile materials
soft rounded forms
subtle imperfections
warm emotional lighting
atmospheric depth
cinematic composition
gentle volumetric light
expressive but natural characters
whimsical realism
```

Do not imitate a specific animation studio, film, living artist or
copyrighted character style.

------------------------------------------------------------------------

# 2. Level of Realism

Target balance:

``` text
Photorealism        ██░░░░░░░░ 20%
Stylisation         ████████░░ 80%
```

Characters should clearly look animated.

Materials and environmental responses should remain believable:

-   Brass behaves like brass
-   Glass behaves like glass
-   Wet fabric appears wet
-   Rain interacts with surfaces
-   Lantern light illuminates nearby objects
-   Hair responds naturally to wind
-   Mud accumulates believably

The world is stylised, but its physical behaviour remains
understandable.

------------------------------------------------------------------------

# 3. Shape Language

Bellwood favours:

**soft curves + gentle irregularity**

Examples:

``` text
slightly uneven stone walls
gently bowed wooden beams
irregular rooflines
rounded doorways
handmade lanterns
worn stone paths
organic forest shapes
```

Avoid overly sharp, sterile or futuristic geometry.

The world should feel handmade and lived in.

------------------------------------------------------------------------

# 4. Texture Language

Surfaces should contain visible but restrained texture.

## Brass

``` text
aged
slightly tarnished
fine scratches
soft highlights
finger-worn edges
```

## Wood

``` text
visible grain
small imperfections
hand-finished
slightly weathered
```

## Stone

``` text
irregular
moss in selected crevices
weathered edges
subtle moisture
```

## Clothing

``` text
visible weave
wool texture
natural folds
subtle wear
```

Avoid excessively smooth, plastic-looking 3D surfaces.

------------------------------------------------------------------------

# 5. Colour Script

Colour should evolve with the emotional arc.

## Act 1 --- Bellwood / Safety

``` text
warm amber
honey gold
soft orange
muted cream
weathered brown
dusky blue
```

**Mood:** safe / cosy / magical

## Act 2 --- Forest Before Storm

``` text
warm late-afternoon gold
natural green
moss green
earth brown
soft sky blue
```

**Mood:** adventure / curiosity

## Act 3 --- Storm

``` text
deep blue-green
navy
slate grey
desaturated green
cold blue
```

Maya's mustard raincoat and Lumi's amber flame remain warm.

**Mood:** danger / isolation

## Act 4 --- Hope

Begin with:

``` text
mostly cold darkness
+

```

Then progressively introduce:

``` text
additional warm lantern lights
```

**Mood:** hope growing

## Act 5 --- Home

``` text
warm amber
gold
soft blue night
gentle cream
```

**Mood:** relief / belonging / understanding

------------------------------------------------------------------------

# 6. Critical Colour Rule

During the storm, do **not** make the entire image warm merely because
Lumi is present.

The environment remains predominantly cold.

Lumi creates only a **small local pool of warm light**.

Central visual contrast:

``` text
large cold darkness
        +
small warm light
```

As villagers raise their lanterns, warm light progressively occupies
more of the composition.

Colour itself participates in storytelling.

------------------------------------------------------------------------

# 7. Lighting

Lighting should feel cinematic but motivated by believable sources.

Primary sources:

``` text
sun
sky
lantern flames
windows
Great Lantern
lightning
```

Avoid unexplained studio-style lighting.

## Lantern Illumination

Lantern light should:

-   Cast warm amber illumination
-   Affect nearby skin and clothing
-   Fall off naturally with distance
-   Create soft local shadows
-   Remain relatively small around Lumi

Lumi must not create giant magical beams.

------------------------------------------------------------------------

# 8. Bellwood

Bellwood must feel geographically coherent.

## Architecture

``` text
small mountain village
old stone houses
dark timber framing
steep roofs
small chimneys
wooden shutters
narrow winding stone streets
handmade lantern brackets
old stone tower
```

## Environment

``` text
mountains surrounding valley
dense forest beyond village
winding paths
small village square
old workshop near village edge
```

The Great Lantern tower is a major landmark visible from multiple
locations and helps orient the audience geographically.

------------------------------------------------------------------------

# 9. The Great Lantern

The Great Lantern should feel impressive enough for Lumi to compare
herself to it.

Design direction:

``` text
very large architectural lantern
mounted at top of old stone tower
aged brass structure
large glass panels
powerful warm flame
visible throughout valley
```

It belongs to the same handcrafted design culture as Lumi.

**Design rule:** Lumi and the Great Lantern should look as though
craftspeople from the same culture could have made both.

------------------------------------------------------------------------

# 10. Forest

The forest begins beautiful and becomes threatening without changing
into a different environment.

## Before Storm

``` text
tall trees
moss
ferns
wildflowers
sun rays
soft mist
winding trail
```

## During Storm

Use the same forest with:

``` text
darker exposure
heavy rain
wind
moving branches
fog
cold palette
reduced visibility
```

Do not transform it into an unrelated horror forest.

------------------------------------------------------------------------

# 11. Cinematography

Primary shot vocabulary:

``` text
ESTABLISHING WIDE
introduce environment

WIDE
character within environment

MEDIUM
character action

CLOSE-UP
emotion / important detail

EXTREME CLOSE-UP
Lumi flame / hand / marker

OVER-THE-SHOULDER
discovery and direction

LOW ANGLE
Great Lantern / imposing scale

HIGH ANGLE
vulnerability / isolation
```

Shot types will be assigned formally during the Scene & Shot List stage.

------------------------------------------------------------------------

# 12. Lens Language

The production does not require technically exact virtual-camera
simulation, but consistent photographic vocabulary should guide
generation.

## Environment

``` text
24–35mm cinematic lens feel
```

## Character Medium Shots

``` text
35–50mm cinematic lens feel
```

## Emotional Close-Ups

``` text
50–85mm portrait lens feel
```

Avoid extreme fisheye perspectives unless specifically required.

------------------------------------------------------------------------

# 13. Depth of Field

Use moderate depth of field.

Characters should generally remain fully readable.

Close-ups may use shallower depth of field to isolate emotional
information.

Example:

``` text
Lumi sharp in foreground
Bellwood lanterns softly blurred behind
```

Do not blur backgrounds so aggressively that environmental storytelling
is lost.

------------------------------------------------------------------------

# 14. Camera Movement

Image-to-video animation should favour restrained movement:

``` text
slow push-in
slow pull-back
gentle pan
gentle tilt
controlled tracking
subtle handheld movement during storm
```

Avoid:

``` text
wild orbiting camera
constant zoom
rapid drone movement
unmotivated camera spins
```

Simple, motivated camera instructions are preferred for AI video
generation.

------------------------------------------------------------------------

# 15. Weather Progression

The storm escalates through defined continuity stages.

## Stage A

``` text
distant clouds
subtle wind
```

## Stage B

``` text
darkening sky
stronger wind
first rain
```

## Stage C

``` text
heavy rain
branches moving
poor visibility
lightning
```

## Stage D

``` text
storm beginning to weaken
```

## Stage E

``` text
rain stopped
clouds separating
wet reflective surfaces
```

Weather state must follow the story timeline rather than changing
randomly between shots.

------------------------------------------------------------------------

# 16. Rain Production Strategy

Rain is difficult for generative video systems to maintain consistently.

The studio will not force every animation model to solve complex rain.

Where appropriate, the production may combine:

``` text
base animation
+
AI-generated weather
+
editing overlays/effects
+
sound design
```

## Studio Principle

> Do not force one AI tool to solve every visual problem.

Use the production pipeline to combine specialised tools when that
produces a cleaner result.

------------------------------------------------------------------------

# 17. Composition

Important subjects require clear silhouettes.

Avoid visual clutter directly behind:

-   Maya's face
-   Lumi
-   Stone markers
-   Important hand actions

When Lumi is narratively important, guide attention using:

-   Contrast
-   Light
-   Framing
-   Focus

Do not make Lumi unrealistically large merely to increase visual
prominence.

------------------------------------------------------------------------

# 18. Facial Expressions

Maya's expressions should be readable but restrained.

Target:

``` text
subtle smile
curious attention
growing concern
fear
concentration
relief
warm affection
```

Avoid:

-   Exaggerated cartoon faces
-   Anime-style eye exaggeration
-   Extreme screaming mouths
-   Facial deformation

------------------------------------------------------------------------

Do not blindly paste a large negative-prompt list into tools that do not

# 20. Production Format

## Aspect Ratio

**16:9 landscape**

## Target Master

``` text
1920 × 1080
24 fps
16:9
```

Some generated assets may use different native resolutions due to tool
limitations, but all composition must protect the final 16:9 frame.

------------------------------------------------------------------------

# 21. Resolution Philosophy

Do not waste limited AI credits chasing unnecessary 4K source
generation.

For Video 01:

``` text
Generate at practical tool resolution
↓
Edit at 1080p
↓
Upscale only if genuinely necessary
↓
Export 1080p master
```

Composition, consistency, lighting and storytelling matter more than
nominal source resolution.

------------------------------------------------------------------------

# 22. Frame Consistency Test

Every important production image will later be evaluated in five
categories.

## 1. Character

Does Maya/Lumi match the approved master reference?

## 2. Style

Does the image belong in the same film?

## 3. Continuity

Does clothing, weather, dirt and damage match this point in the story?

## 4. Composition

Does the shot communicate the intended information clearly?

## 5. Technical

Are there obvious AI artefacts or malformed details?

Production images should be selected for continuity and storytelling,
not merely because they are individually attractive.

------------------------------------------------------------------------

This is the compact visual-language definition.

``` text
Stylised cinematic 3D animated storybook world,

```

Controlled portions of this language will be reused in later character

------------------------------------------------------------------------

# 24. Style Drift Rule

If an image is individually beautiful but looks as though it belongs in
another film:

**REJECT IT.**

The production goal is not:

> Generate the prettiest possible image.

The production goal is:

> Generate the correct next frame from the same film.
