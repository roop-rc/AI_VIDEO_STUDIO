# 1. Purpose

This document converts the approved production script into individual
production shots.

The shot list is the bridge between the written film and asset
generation. It exists to prevent long, uncontrolled AI-generated
sequences and to make character continuity, environment continuity,
camera language, generation cost, and editing requirements explicit
before production begins.

A story beat is not automatically one AI-video generation.

# 3. Shot-Duration Principle

The shot list intentionally uses short controlled production units.

Example:

``` text
01:20–01:36 — Into the Forest

06A — Forest establishing shot          4 sec
06B — Maya walking trail                4 sec
06C — Maya gathers wildflowers          4 sec
06D — Lumi swinging from Maya's hand    2 sec
06E — Storm clouds beginning            2 sec
```

A 16-second story beat should not automatically become one 16-second
AI-video generation.

Shorter shots improve:

-   generation reliability
-   continuity control
-   edit flexibility
-   pacing
-   regeneration cost
-   camera control

# 7. Production Classification

Shots will later be classified according to generation need.

## A --- Hero Generation

Important identity, emotional, story, or composition shot.

Worth allocating a controlled regeneration budget.

## B --- Standard Generation

Needs a dedicated production image but should normally use a small
generation budget.

## C --- Derivative Shot

Can potentially be created using:

-   crop
-   alternate framing
-   reference transformation
-   existing master
-   still-image camera movement
-   compositing

## D --- Editing / Effects Shot

Can largely be created using:

-   editing
-   lighting effects
-   weather overlays
-   titles
-   camera movement from a still
-   compositing
-   sound design

The final A/B/C/D classification will be refined after environment
masters and storyboard planning.

# 9. Video-Generation Strategy

Do not animate every shot immediately.

Production sequence:

``` text
approved stills
↓
rough storyboard / animatic
↓
voiceover and timing check
↓
identify shots where real motion matters
↓
animate priority shots first
↓
use editing movement where appropriate
```

Examples likely to benefit from actual animation:

-   Maya walking
-   Lumi swinging
-   storm clouds forming
-   wind and rain
-   branches moving
-   Lumi's flame struggling
-   Maya cupping Lumi
-   villagers raising lanterns
-   growing path of lights
-   Maya running home

Examples potentially achievable from still imagery:

-   slow push-ins
-   slow pull-backs
-   some establishing shots
-   close-ups with subtle camera movement
-   title/end card

# 11. Generation Budget Rule

Every generative task must declare its attempt budget before generation
begins.

Example:

``` text
Environment master: Workshop
Initial budget: 1 generation
Review before second attempt
```

If the budget is exhausted:

``` text
STOP
↓
Review
↓

prompt
reference
tool
composition
or unrealistic requirement
↓
change strategy before spending more credits
```
