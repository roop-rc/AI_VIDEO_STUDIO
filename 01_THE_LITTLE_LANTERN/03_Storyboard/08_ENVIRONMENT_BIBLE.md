------------------------------------------------------------------------

# 1. Purpose

The Environment Bible defines the recurring geography, architecture,
materials, colour language, landmarks, spatial relationships, and
continuity rules of Bellwood and the surrounding forest.

The objective is to make the film feel as though every shot occurs in
one coherent world rather than in unrelated AI-generated locations.

We lock environmental identity, not every pixel.

------------------------------------------------------------------------

# 2. World Geography

Bellwood sits in a small mountain valley surrounded by snowy peaks and
dense evergreen forest.

``` text
                    SNOWY MOUNTAINS

                         NORTH
                           ↑

                  GREAT LANTERN TOWER
                          │
                   VILLAGE SQUARE
                          │
        HOUSES ───── MAIN STREET ───── HOUSES
                          │
                     WORKSHOP
                          │
                    VILLAGE EDGE
                          │
                     FOREST PATH
                          │
               STONE DIRECTION MARKERS
                          │
                    DEEPER FOREST
```

This is story geography rather than a literal architectural blueprint.

Maya travels outward from Bellwood through the forest. Stone direction
markers provide a plausible route back toward the village.

------------------------------------------------------------------------

# 3. Bellwood Identity

Bellwood is a small, old, inhabited mountain community rather than a
giant fantasy city.

Approximate visual impression:

``` text
40–70 buildings
small enough for residents to know one another
```

Buildings cluster naturally around winding streets rather than a modern
grid.

## Architecture

``` text
old grey stone
dark weathered timber
steep pitched roofs
small chimneys
wooden shutters
small warm windows
iron and brass lantern brackets
worn stone streets
occasional stone steps
```

Roof materials:

``` text
dark slate
weathered wooden shingles in selected buildings
```

Individual houses should vary naturally.

------------------------------------------------------------------------

# 4. Bellwood Silhouette

From a distance, Bellwood should remain recognisable through:

``` text
mountain valley
+
cluster of steep-roofed houses
+
Great Lantern tower
```

The Great Lantern tower is the primary landmark.

Minor house variations are acceptable if these core geographic signals
remain stable.

------------------------------------------------------------------------

# 5. Great Lantern Tower

## Tower

``` text
old stone watchtower
roughly 4–5 storeys tall
square base
slightly tapered upper section
weathered grey stone
small narrow windows
simple timber door at ground level
```

Avoid castle battlements, palatial scale, and elaborate fantasy
architecture.

## Great Lantern

Mounted at the top:

``` text
large architectural lantern
aged brass
large glass panels
warm flame
visible across valley
```

The Great Lantern should feel like a vastly enlarged cultural relative
of Lumi without being an exact enlarged copy.

The tower must rise clearly above surrounding rooftops so that it can
function as a distant navigation landmark.

------------------------------------------------------------------------

# 6. Village Square

The Great Lantern tower sits on or immediately beside a modest central
square.

Features:

``` text
irregular stone paving
old stone tower
small gathering space
nearby houses
wooden benches
simple water trough or small fountain
lantern brackets
```

It is not an enormous civic plaza.

The square must plausibly accommodate approximately 20--50 visible
villagers during the climax.

------------------------------------------------------------------------

# 7. Main Street

A gently winding stone street connects the central square toward the
village edge.

Characteristics:

``` text
narrow
pedestrian-scale
old stone paving
houses close to street
warm windows
hanging lanterns
occasional steps
subtle elevation changes
```

This street is especially important for the final sequence in which Maya
carries Lumi home.

------------------------------------------------------------------------

# 8. Workshop Exterior

The lantern workshop sits near Bellwood's edge, reasonably close to the
route leading toward the forest.

``` text
small two-storey stone-and-timber building
dark timber beams
warm windows
weathered wooden door
small hanging brass lantern sign
steep slate roof
small chimney
```

Avoid readable text on the sign. A lantern-shaped symbol is sufficient.

------------------------------------------------------------------------

# 9. Workshop Interior

The workshop is cosy, warm, practical, and handmade.

Approximate story layout:

``` text
              BACK WALL

      shelves of lanterns
    ┌──────────────────────┐
    │                      │
    │ workbench      shelf │
    │                LUMI  │
    │                      │
    │ counter              │
    │                      │
    │              window  │
    │                      │
    └─────── entrance ─────┘
```

## Materials

``` text
dark warm wood
aged brass
stone wall sections
worn workbench
glass
tools
small drawers
wooden shelves
```

## Lighting

``` text
lanterns
small window
optional fireplace/stove glow
```

The workshop should feel warmer than the exterior village.

------------------------------------------------------------------------

# 10. Lumi's Shelf

Lumi sits:

``` text
on a wooden shelf
approximately Maya's chest height
near a window
among several larger and more decorative lanterns
```

The surrounding lanterns reinforce Lumi's insecurity.

They should make Lumi appear smaller, older, and simpler---not ugly,
broken, or worthless.

------------------------------------------------------------------------

# 11. Workshop Window Geography

From Lumi's position near the window, she can plausibly see:

``` text
Bellwood rooftops
+
distant Great Lantern tower
```

The tower may be small in the window. It should not unrealistically
dominate the view.

This supports early comparison shots without breaking geography.

------------------------------------------------------------------------

# 12. Forest Edge

The transition from Bellwood to forest is gradual:

``` text
last village houses
↓
stone wall / wooden fence
↓
grassy verge
↓
scattered trees
↓
dense forest
```

Avoid an abrupt village-to-jungle transition.

------------------------------------------------------------------------

# 13. Forest Identity

Bellwood is surrounded by a cool-climate mountain forest.

Primary vegetation:

``` text
spruce
fir
pine
moss
ferns
small woodland plants
wildflowers
```

Some deciduous trees are acceptable, but evergreen trees dominate the
silhouette.

Ground:

``` text
earth
stones
roots
fallen needles
moss
ferns
small flowers
```

Avoid tropical vegetation.

------------------------------------------------------------------------

# 14. Main Forest Path

Maya follows an established but modest trail approximately 1--1.5 metres
wide.

``` text
packed earth
embedded stones
tree roots
occasional muddy areas
gentle curves
moderate slope changes
```

In good weather it should look safe enough for a child to explore.

------------------------------------------------------------------------

# 15. Wildflower Area

Maya gathers flowers near the established path.

Use small mountain wildflowers:

``` text
white
pale yellow
soft purple
occasional blue
```

Avoid oversized fantasy flowers.

------------------------------------------------------------------------

# 16. Stone Direction Markers

The markers must be simple and reproducible.

``` text
low weathered stone marker
roughly knee height to Maya
rectangular / slightly irregular stone
simple deeply carved arrow
moss around base
```

No writing, letters, or elaborate symbols.

The carved arrow points toward Bellwood.

------------------------------------------------------------------------

# 17. Marker Geography

Markers occur at trail junctions.

The story only needs the audience to understand:

``` text
marker
↓
Maya follows
↓
another marker
↓
she knows she is heading toward Bellwood
```

Approximately 2--3 markers may appear visually.

------------------------------------------------------------------------

# 18. Forest Viewpoint Toward Bellwood

At least one location provides a partial valley view:

``` text
forest trail
↓
small rocky rise / clearing
↓
gap between trees
↓
valley view
↓
Bellwood in distance
```

This supports the shots in which Maya sees Bellwood faintly and then
witnesses the Great Lantern go dark.

The storm progressively reduces visibility.

------------------------------------------------------------------------

# 19. Storm Forest

The storm environment remains the SAME forest.

Transform:

``` text
LIGHT
warm → cold

VISIBILITY
clear → obscured

GROUND
dry → wet/muddy

TREES
still → moving

AIR
clear → rain/mist

SKY
golden → slate/navy
```

Do not suddenly introduce horror trees, swamps, giant cliffs, ruins, or
unrelated fantasy geography.

------------------------------------------------------------------------

# 20. Path-of-Lights Geography

The climax does not require villagers to instantly travel miles into
dangerous forest.

The visual path grows through:

``` text
village square
↓
main street
↓
village edge
↓
first section of forest road/path
```

Villagers carrying lanterns create a visible corridor pointing toward
home.

Cinematic depth may exaggerate the apparent distance while preserving
plausible geography.

------------------------------------------------------------------------

# 21. Final Bellwood Street

The ending uses a quieter residential street.

``` text
wet stone paving
warm windows
small hanging lanterns
stone-and-timber houses
soft mist
reflections on wet ground
Great Lantern visible in distance where composition allows
```

Lumi illuminates only the next few stones, visually supporting the final
narration.

# 24. Environmental Scale

Bellwood remains intimate:

``` text
2–3 storey houses
narrow streets
small square
modest workshop
one dominant tower
```

The Great Lantern tower is deliberately the vertical exception.

------------------------------------------------------------------------

# 25. Negative Environment Rules

Avoid:

``` text
modern city
cars
roads with markings
electric streetlights
power lines
satellite dishes
modern signage
skyscrapers
modern glass
neon
traffic lights
asphalt streets
modern umbrellas
huge castle
giant palace
gothic horror city
steampunk machinery
fantasy airships
magic crystals
tropical plants
desert vegetation
random snow inside village during the storm
unreadable AI text signs
```

The world is restrained fantasy rather than spectacle-driven fantasy.

# 26. Environment Reference Strategy

Seven initial masters:

``` text
ENV_01_BELLWOOD_AERIAL
ENV_02_GREAT_LANTERN_TOWER
ENV_03_WORKSHOP_INTERIOR
ENV_04_FOREST_PATH_DAY
ENV_05_FOREST_PATH_STORM
ENV_06_VILLAGE_SQUARE
ENV_07_BELLWOOD_STREET_NIGHT
```

Where possible, weather/state variants should derive from an approved
environment master rather than being invented independently.

Example:

``` text
ENV_04 Forest Day
↓
reference-controlled transformation
↓
ENV_05 Same Forest — Storm
```

Likewise, Bellwood night/storm variants should preserve established
Bellwood identity.

# 29. Geographic Consistency Hierarchy

Preserve these first:

``` text
1. Great Lantern tower above rooftops
2. Bellwood situated in mountain valley
3. Forest outside village
4. Workshop near village edge
5. Square associated with tower
6. Main street connecting square toward edge
7. Forest path leading away from Bellwood
8. Stone markers pointing home
```

Minor background-house details have much lower priority.

------------------------------------------------------------------------

# 30. Environment Lock Philosophy

We lock identity rather than every pixel.

Bellwood can tolerate minor changes to individual background buildings.

It cannot become:

-   a different architectural culture
-   a giant city
-   a castle complex
-   a flat farming village
-   a modern town

The forest can tolerate changes to individual trees.

It cannot become a tropical rainforest or unrelated fantasy biome.
